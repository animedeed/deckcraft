# Каталог макетов (архетипы)

Координаты — дюймы на слайде 13,333 × 7,5, колонки — по сетке 12 (`Grid.x/w`). У каждого слайда в `Slide(layout=…)` указывается архетип: по ним `lint()` проверяет разнообразие (на 8 слайдов подряд ≥ 6 разных).

Общая шапка: метка раздела `!!sec` (y 0,55), заголовок `!!ttl` (y 0,9–1,0), колонтитул `!!folio` справа внизу. Шапка — сквозные якоря Morph.

## 1. cover — титул
```
┌──────────────────────────────────────────────┐
│ МЕТКА · КОНТЕКСТ                             │
│                                   ┌────────┐ │
│ Большой заголовок                 │ мотив  │ │
│ в две строки (display)            │ (кол.  │ │
│                                   │ 9–12)  │ │
│ Подзаголовок lead, 2 строки       └────────┘ │
│                                              │
│ мета: данные · метрика             01 / 18   │
└──────────────────────────────────────────────┘
```
Текст — колонки 1–8, мотив — 9–12.

## 2. route — карта маршрута (мир + камера)
Узлы этапов в мировых координатах, связи с потоками. Общий план → полёт камеры к текущему этапу. Первый и последний слайд презентации «рифмуются» этим макетом.

## 3. statement — одно утверждение
Крупная фраза (h1–display) в колонках 1–9, под ней одна строка пояснения. Для смены раздела и главного вывода.

## 4. split — текст + визуал
Колонки 1–5: заголовок, 3–5 пунктов; 6–12: схема, код, график. Варианты 4+8, 6+6.

## 5. pipeline — конвейер
Ряд из 4–6 узлов (`Kit.node`) по всей ширине (y ≈ 2,4–3,6), соединители `Kit.link` с потоками `flow`. Ниже — 2–3 карточки пояснения. Морф: активный узел меняет цвет (приём 5), петли переезжают.

## 6. metrics — числа
3–4 `Kit.stat` в ряд (колонки по 3 или 4), под ними одна строка вывода. Большое число — accent, подпись — ink2. Цифры вырастают из нулевого состояния.

## 7. compare — сравнение
Две колонки 6+6 (или 5+2+5 с вертикальной линейкой), одинаковая структура строк. Вердикт — внизу или подсветкой выигравшей колонки. Приём: раскол экрана (10).

## 8. code — код и пояснения
Панель кода (`Kit.code`) колонки 1–7, справа 8–12 — пояснения к строкам; подсвеченные строки `highlight=[…]`. Морф между двумя слайдами: подсветка переезжает по строкам.

## 9. terminal — запуск и вывод
`Kit.terminal` с мигающим курсором (`Loop("blink", target=…)`) + комментарий к выводу. Для «повторяемого запуска».

## 10. table — таблица из фигур
`Kit.table` с выделенной строкой (`highlight`). Не больше 6–7 строк; больше — делить.

## 11. chart — график из фигур
`Kit.bars` (горизонтальные, длинные подписи) или `Kit.columns` (по категориям), подписи у концов. Справа или снизу — вывод в одну-две строки. Нулевое состояние → значения.

## 12. tree — структура файлов
`Kit.tree` слева, справа пояснения «что где лежит и зачем». Выделить файлы текущего шага.

## 13. grid — матрица карточек
2×2, 2×3, 3×2 карточки `Kit.card` одинакового размера. Морф: одна карточка раскрывается (7), остальные сжимаются.

## 14. qa — вопросы защиты
3 карточки-вопроса; ответ появляется после перехода (`anim_*`) или на следующем слайде вопрос раскрывается в панель с ответом (приём 7).

## 15. callout — типовая ошибка / предупреждение
`Kit.callout(tone="warn"|"bad")` + пример «как неправильно / как правильно» (две колонки кода или текста).

## 16. timeline — этапы во времени
Горизонтальная шкала с отметками; маркер «момент» (пульс) делит «известно до» и «известно после».
