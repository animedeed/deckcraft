# Каталог приёмов Morph: 59 рецептов

У каждого приёма указано:
- **смысл** — когда он объясняет, а не украшает;
- **рецепт** — что стоит на слайдах N и N+1;
- **помощник** — функция движка;
- **ловушки**.

`R` — `morphkit.recipes`, `V` — `morphkit.vector`, `K` — `Kit`.

Проверенные примеры:
- `scripts/gallery_vector.py` — вектор и 3D;
- `scripts/examples/demo_deck.py` — презентация с нуля по брифу: мотив в ролях, навигация, языки движения разделов.

**Общие правила.**
- Один приём — одна мысль. На соседних переходах приёмы разные, кроме серий: колесо, прожектор, шаги одного процесса.
- Длительности: 0,5–0,8 с — мелкая правка, 1,0–1,6 с — перестройка сцены, 1,6–2,2 с — полёт камеры. Служебный промежуточный слайд (`auto=0`) — 0,4–0,6 с.
- Перед сборкой распиши раскадровку: что на N, что на N+1, какие пары, что паркуется.

## A. Камера и пространство

1. **Камера над холстом.**
   - Смысл: общий план → деталь.
   - Рецепт: мир `world=True`, на каждом слайде своя `Cam(cx, cy, z)` (раздел 7 SKILL.md).
   - Ловушка: на крупном плане не держи гигантские подписи общего плана — гаси их.
2. **Параллакс.**
   - Смысл: глубина при полёте камеры.
   - Рецепт: фоновый слой `meta={"parallax": 0.3}`.
3. **Матрёшка (бесконечный зум).**
   - Смысл: «внутри узла — целая схема».
   - Рецепт: N — узел обычного размера; N+1 — камера z×8 на узел, узел стал фоном-рамкой, внутри проявляется его схема (объекты без пары); N+2 — новый мир с той же рамкой в роли границы.
   - Ловушка: внутренняя схема на N уже должна существовать крошечной (z мал) внутри узла, иначе она просто проявится, а не «приблизится».
4. **Лента времени.**
   - Смысл: события по годам.
   - Рецепт: мир-лента шириной 3–5 слайдов, камера едет вправо; текущий год крупно, соседние мельче (масштаб от расстояния до центра).
5. **Карта разделов → шапка.**
   - Рецепт: карточки разделов на титуле; на слайде раздела его карточка уезжает в угол и сжимается в метку, остальные паркуются за краем.
6. **Карточка становится фоном (morph-through).**
   - Смысл: «заходим внутрь».
   - Рецепт: N — карточка `!!c`; N+1 — та же `!!c` размером со слайд (с запасом 0,3″), её цвет — фон нового слайда; содержимое нового слайда без пар проявляется.
   - Ловушка: текст карточки на N+1 убрать или увести, иначе он раздуется.
7. **Круг-граница раздела.** *Отвергнут профилем по умолчанию: меняет стиль посреди презентации; только если профиль разрешает.*
   - Рецепт: `R.circle_wipe(id, cx, cy, color, grown=False/True)`. Круг цвета нового раздела вырастает из точки-«кнопки» и заливает слайд. Следующий слайд уже с фоном этого цвета.
   - Ловушка: точка-источник на N — заметный элемент, иначе рост «ниоткуда».

## B. Схемы и процессы

8. **Рисование линии.**
   - Рецепт: N — линия длины 0 в начальной точке; N+1 — полная.
9. **Рисование ломаной.**
   - Рецепт: `R.draw_polyline(id, pts)` → объекты + `Fx("entrance_wipe")` по сегментам в направлении движения.
   - Ловушка: сегменты — новые объекты без пар (вход на парах запрещён).
10. **Импульс по ребру.**
    - Рецепт: маленький круг `!!pulse` на N в источнике, на N+1 — у приёмника. Ребро подсвечено рамкой или потоком, а не перекраской.
11. **Смена шага — рамкой.**
    - Рецепт: `K.marker(узел)` — пара `!!marker` переезжает к новому узлу. Перекраска далёких цветов даёт грязь (раздел 9 SKILL.md, п. 6а).
12. **Поток данных (петля).**
    - Рецепт: `K.link` + `K.flow` (`references/loops.md`). Точки скрыты до старта и не мелькают при переходе.
13. **Событие здесь (петля).**
    - Рецепт: `Loop("ripple")` — круги на воде у узла, где что-то произошло.
14. **Прожектор.**
    - Смысл: «смотрим сюда» на плотной схеме или таблице.
    - Рецепт: `R.spotlight(id, (x, y, w, h))` — затемнение слайда с одной дыркой. Окно на соседнем слайде переезжает и меняет размер. Morph переливает фигуру с одной дыркой (не больше одной).
    - Слой: z=15 — выше содержимого, ниже заголовков.
    - Запасной вариант: `R.spotlight4` (четыре прямоугольника).
15. **Скользящее окно по таблице.**
    - Рецепт: серия прожекторов: вся таблица → группа строк → наша строка. Вывод проявляется на последнем шаге (`anim_*`).
16. **Рост сети.**
    - Рецепт: N — все узлы в центре-источнике размером 0; N+1 — на своих местах, рёбра от длины 0. Второй шаг: петли потоков.
17. **Список → слои архитектуры.**
    - Рецепт: плашки списком → `V.rot3d(**R.ISO_TOP_UP, depth=8)` стопкой с шагом по y (`references/vector.md`).
18. **Раскрытие узла в карточку.**
    - Рецепт: узел `!!n` растягивается в панель с подробностями; соседние узлы сжимаются в таблетки по краю.

## C. Данные

19. **Столбики из нуля.**
    - Рецепт: `K.bars/columns(zero=True)` → значения; `R.ranked_bars(zero=True)` → значения.
20. **Пересортировка.**
    - Смысл: «кто лучше».
    - Рецепт: `R.ranked_bars(order="given")` → `order="desc"`. Имена по сущности, поэтому столбики переезжают на новые места.
21. **Кольцо-прогресс.**
    - Рецепт: `objs, fx = R.ring_fill(id, cx, cy, r, frac)` — дуга сразу нужной длины от 12 часов + вход «Колесо» с одной спицей: кольцо заполняется по кругу при входе на слайд.
    - Ловушка: регулятор дуги Morph-ом не растить — PowerPoint рисует промежуточный клин («треугольник»).
22. **Стрелочный индикатор.** *Удалён по отзыву пользователя (некрасивое полукруглое заполнение).*
23. **Одометр.** *Удалён по отзыву пользователя: при входе и уходе со слайда маски гаснут вместе с колонками цифр — видны «фантомные» числа. Числа появляются эффектом (`R.reveal(..., "entrance_faded_zoom")`).*
24. **Сетка → разброс.**
    - Смысл: «каждая точка — наблюдение, вот где она на графике».
    - Рецепт: `R.dots(id, R.grid(...))` → `R.dots(id, R.scatter(...))`.
25. **Поле → группы.**
    - Смысл: train / val / test, классы, сегменты.
    - Рецепт: `R.groups(sizes, boxes, step)`. Порядок точек сохраняется, поэтому первые `sizes[0]` уходят в первую группу. Цвета групп — близкие или из одной роли.
26. **Поле → гистограмма.**
    - Рецепт: `R.histogram(values, bins, ...)` — точки встают в стопки своих интервалов.
27. **Схлопывание 99 → 15.**
    - Рецепт: лишние точки — размер 0 на месте; оставшиеся собираются в плотный блок (`R.grid(keep, ...)`). Рядом число 99 → 15 (старое гаснет, новое появляется).
28. **Интервалы от нуля.**
    - Рецепт: усы доверительных интервалов длины 0 на нулевой линии → раскрываются; точка-оценка едет к значению.
29. **Разлёт точек из начала координат.**
    - Рецепт: `R.pile(n, x0, y0)` → `R.scatter(...)`.
30. **Пирог по кускам.**
    - Рецепт: секторы `V.sector` — целое кольцо → один сектор выдвигается наружу (смещение по биссектрисе) → подпись.
31. **Матрица по строкам.**
    - Рецепт: точки-ячейки; строка «наш вариант» проявляется после Morph через `anim_*`.

## D. Формы и вектор (`references/vector.md`)

32. **Перелив формы.**
    - Рецепт: `V.resample(g, n)` у обеих форм: круг → звезда → капля. Не больше одной дырки.
33. **Фрагментация и разлёт.**
    - Рецепт: `V.fragment` → кусочки на месте → `R.explode(parts, k)`.
34. **Сборка пазла.**
    - Рецепт: обратный ход 33: кусочки из разлёта собираются в целое, последний — акцентом.
35. **Колесо / цветок.** *Полушаги и «колесо в угол» отвергнуты пользователем (прыжки, не видно поворота). Правильная роль цветка — указатель темы, наполовину за краем экрана (фаза 3, `pptx-design`).*
    - Рецепт: лепестки `V.petal` в рамке на оси (`pivot`); поворот на шаг кладёт активный на 12 часов. Активный выдвигается — другой контур с тем же числом точек.
    - Шаг больше 45° делится на полушаги (`auto=0`), чтобы подписи не срезали хорду.
36. **Вход «Вертушка» из центра.**
    - Рецепт: `Fx("entrance_spinner")` на лепестках в рамке на оси — раскручиваются из общего центра. Задержки 0,08–0,12 с.
37. **Орбита.**
    - Рецепт: спутник в рамке на оси солнца; поворот рамки ведёт его по дуге. Шаг < 180°.
38. **Живой фон.**
    - Рецепт: 2–3 больших размытых пятна (свободные формы, `fa=0.15–0.3`) медленно меняют положение и форму на каждом слайде раздела. Длительность Morph 1,6–2 с.
    - Ловушка: контраст текста проверяй по самому светлому месту.

## E. Карточки и навигация

39. **Раскрытие карточки.**
    - Рецепт: карточка из ряда растягивается в панель, соседи сжимаются в таблетки.
40. **Рельс шагов.**
    - Рецепт: `K.rail(steps, active)`. Текущая таблетка раскрыта.
41. **Веер / стопка.**
    - Рецепт: карточки стопкой → веером, `rot = (i − k)·2–4°`.
42. **Карусель.**
    - Рецепт: `R.carousel(n, active, ...)` — места на эллипсе (спереди крупно, сзади мельче и бледнее). Шаг на одну позицию — Morph по хорде; при n < 6 добавь полушаги.
43. **Раскол экрана.**
    - Рецепт: две панели паркованы за краями, разделитель длины 0 → панели въезжают, разделитель растёт.
44. **Вкладки с бегунком.**
    - Рецепт: ряд вкладок; бегунок-подчёркивание `!!tab` переезжает под новую вкладку и меняет ширину; содержимое меняется затуханием.
45. **Аккордеон.**
    - Рецепт: разделы-полоски; открытый раздел растёт по высоте, остальные сдвигаются; текст открытого проявляется.
46. **Переворот карточки.**
    - Рецепт: `R.flip_fx(лицо, оборот)` — внутри слайда: выход «Поворот» лица и вход «Поворот» оборота по горизонтали. Служебные слайды не нужны.
47. **Наклон к зрителю.**
    - Рецепт: `V.rot3d(x=15–25, camera="perspectiveFront")` у выбранной карточки, остальные плоские — фокус без увеличения.

## F. Текст

48. **Заголовок перетекает.**
    - Рецепт: `!!ttl` с новым текстом. Короткие правки — `mode="byWord"`.
49. **Правка по буквам.** *Ограничено профилем: режим действует на ВСЕ тексты слайда, буквы улетают в номер страницы и соседние надписи. Разрешён, только если текст на слайде один; иначе правка — зачёркивание старого значения и появление нового.*
    - Смысл: «изменилось одно число».
    - Рецепт: `mode="byChar"`: «12 лет» → «10 лет» — стоят все буквы, кроме одной цифры. Рядом рамка на типе правки.
    - Ловушка: режим действует на весь слайд — остальные объекты с текстом тоже морфятся по буквам.
50. **Кинетическая типографика.**
    - Рецепт: одно-два огромных слова (display 80–140 pt) меняются местами, масштабом и цветом по ритму речи; соседние слова паркуются за краями.
    - Мера: один такой эпизод на презентацию — на тезис или вывод.

## Как придумать новый приём (протокол)

1. Сформулируй, **что меняется в смысле**: появилось, переехало, выросло, разделилось, совпало, исчезло.
2. Найди **сохраняющийся объект** — пару Morph, которая несёт связность («это тот же документ, та же точка»).
3. Разложи движение на то, что Morph делает хорошо: положение, размер, поворот вокруг центра рамки, регуляторы, обрезка, 3D-поворот, перелив свободной формы с равным числом точек, близкие цвета. Остальное — обходом:
   - дуга — рамка на оси;
   - маска — фигура с одной дыркой или сплошные маски;
   - длинный поворот — полушаги;
   - новое содержимое — `anim_*` / `Fx` после перехода;
   - процесс — петля.
4. Запиши рецепт в этот каталог с помощником, если код нетривиален, и добавь слайд в галерею с заметкой «что проверить».
5. Проверь показом в PowerPoint и запиши вывод в раздел «Выводы из показов» в `WORKLOG.md` проекта.


## G. Рост и непрерывность без служебных слайдов (после отзыва пользователя)

51. **Рост внутри слайда.**
    - Смысл: числа, столбики, точки «вырастают» при входе.
    - Рецепт: `R.reveal(имена, эффект, stagger)`. Столбики — `entrance_wipe {direction: left}`, колонки — `{direction: down}`, точки и подписи — `entrance_fade`, числа — `entrance_faded_zoom`, листы — `entrance_rise_up` слева направо. Показ остаётся одним кликом, назад листается нормально.
52. **Мир уходит на фон.**
    - Рецепт: `R.backdrop(world, k=0.3)` — тот же граф с прозрачными заливками и линиями и тихим текстом. Имена сохраняются, поэтому Morph приглушает мир, а не убирает его. Обычно со сдвигом или отъездом камеры.
53. **Сигнал по линии.**
    - Рецепт: `R.flow_along(линия, cam)` — поток строго по геометрии соединителя (для мира — с камерой), `trim` не доходит до подписей.
54. **Листы-документы.**
    - Рецепт: `R.doc_arc(id, n, …)` — лента листов с загнутым углом дугой, выделенный лист с контуром акцента. `R.doc_pictograms(id, 3.3, …)` — значение в листах (целые + полоска дробной части). Появление — `R.reveal(..., "entrance_rise_up")` слева направо.


## H. Геройские трансформации (фаза 3; галерея `scripts/gallery_hero.py`, тема «Тушь»)

55. **Цветок-мандала из многослойных лепестков** (эталон — видео пользователя: Merge Shapes → Fragment).
    - Рецепт: `R.mandala(id, center, petals, length, width, turn, scale)`. Лепесток — `V.bud`: вложенные линзы с общей вершиной у центра → полосы-полумесяцы (светлый/серый градиент) + тёмное ядро. Каждый лепесток — группа, лежит поверх предыдущего; кант по краю.
    - Вход — `R.mandala_spin_in` («Вертушка» по лепесткам из центра).
    - Форма одна и та же при любом `scale`: Morph меняет только рамку (поворот и размер), без перелива.
56. **Цветок — указатель темы за краем экрана.**
    - Рецепт: центр цветка у левого края (половина за экраном), `turn` такой, чтобы лепесток темы смотрел вправо; неподвижный указатель `R.pointer_lens` — контур с янтарной подсветкой. Смена темы = поворот цветка на шаг (< 180°), номер и название темы гаснут/появляются.
    - Ловушка: не таскать цветок по углам — он стоит на месте и только вращается.
57. **Лепесток → панель.**
    - Рецепт: указатель-линза (`pointer_lens`, n точек) переливается в панель содержимого (`panel_from_lens`, те же n точек); цветок отъезжает дальше за край и уменьшается. Обратный ход — панель сворачивается в лепесток.
58. **Документы → узлы графа** (носители непрерывности).
    - Рецепт: те же объекты-листы (`R.doc_arc`, имена `!!doc{i}`) на следующем слайде уменьшаются и расходятся по кругу узлами; рёбра растут из центра; сигнал — `R.flow_along` по ребру.
59. **Фрагменты → карточки и «жидкая» смена раздела.**
    - Фрагменты диаграммы (`V.fragment`, `V.resample(…, 120)`) переливаются в карточки сетки (`V.resample(V.rect(…), 120)`), подпись — по принадлежности кусочка кругам.
    - Раздел меняют большие «капли» (свободные формы по 200 точек), которые перетекают и растут, — новый раздел без смены стиля.

## Отвергнутые приёмы (по записям показа пользователя)

| Приём | Что пошло не так | Чем заменить |
|---|---|---|
| Нативный переход (куб и т. п.) на каждой смене раздела | «очень лишний», «удешевляет всю презентацию» | смена раздела трансформацией (камера, указатель, карта → шапка); нативные — только по просьбе, коротко |
| Контур из 34–48 точек равномерным шагом | кончики лепестков и углы срезаны площадками, на кривых видны грани | `resample` сохраняет углы и даёт ≥ 120 точек; при записи в pptx кривые сглаживаются сплайном (`smooth_ring`); lint «грубый контур» |
| Слои цветка полосами-полумесяцами с обводкой цветом фона | «прорывы» и белые швы между частями | целые лепестки стопкой (`bud(nested=True)`), тонкий тёмный кант по краю — как в эталонном видео |
| Низ бочки прямой линией | бочка плоская, обручи не повторяют объём | клёпки и обручи по эллипсу цилиндра (`rim(y, t)`) |
| Разовый нативный переход посреди презентации (один куб, один занавес, один наезд) | «как будто впихнуто один раз»: зритель ждёт такой же смены на каждом разделе | акцент — система: один тип на всех границах разделов (`combine.transition_pattern`), «финальный» (занавес) — только в конце; наезд смотрелся лучше всех |
