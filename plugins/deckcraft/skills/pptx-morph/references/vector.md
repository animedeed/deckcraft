# Вектор и 3D: `morphkit.vector`

Модуль строит геометрию в shapely (`pip install shapely`) и превращает её в свободную форму `a:custGeom` (`O(kind="vec")`). Координаты — дюймы слайда или мира (`world=True`), ось y направлена вниз. Это программный аналог меню PowerPoint «Формат фигуры → Объединить фигуры» (Merge Shapes), только воспроизводимый и с точным контролем точек.

Посмотреть всё глазами: `python scripts/gallery_vector.py OUT_DIR --check` → `vector_gallery.pptx`. В колоде цветок со входом «Вертушка», колесо Morph, перелив форм, фрагментация с разлётом, 3D-переворот, изометрическая стопка и орбита. В заметках каждого слайда написано, что проверить в показе.

## Примитивы и операции

| Функция | Что даёт |
|---|---|
| `circle(cx, cy, r)`, `ellipse`, `rect(x, y, w, h, r=скругление)`, `polygon(pts)`, `regular(cx, cy, r, n)`, `star(cx, cy, r_out, r_in, n)` | базовые формы |
| `sector(cx, cy, r_out, a0, a1, r_in=0)` | сектор или сегмент кольца (диаграмма-«пончик» из форм, циферблат) |
| `lens(center, r, gap, angle)` | линза — пересечение двух кругов |
| `petal(pivot, r_in, r_out, width, angle=-90)` | лепесток от r_in до r_out вокруг оси (линза нужной длины и ширины) |
| `union(*g)` | Union — объединение |
| `intersect(a, b)` | Intersect — пересечение |
| `subtract(a, *b)` | Subtract — вычитание |
| `combine(a, b)` | Combine — исключение |
| `fragment(*g)` | Fragment — все кусочки, на которые фигуры режут друг друга |
| `slices(g, n, pivot)` | режет фигуру на n равных секторов |
| `rotate(g, deg, origin)`, `move(g, dx, dy)`, `scale(g, k, origin)`, `radial(g, n, pivot)` | преобразования; `radial` — n копий вокруг оси |
| `resample(g, n=160, start="top")` | контур ровно из n точек, обход по часовой стрелке, старт с верхней точки — подготовка к морфингу |
| `shape(name, g, pivot=None, rot=0, frame=None, fill, ln, lw, grad, d3, …)` | объект `O` |
| `gradient(stops, angle=90, kind="linear"\|"radial"\|"rect")` | градиент (стоп — `(позиция, роль\|hex[, непрозрачность])`) |
| `rot3d(x, y, z, depth, depth_color, bevel, camera, fov, material)` | 3D-поворот и выдавливание (`O.meta["d3"]`) — для любой фигуры, не только `vec` |

Градиент и 3D подходят любому объекту: `O(..., meta={"grad": V.gradient(...), "d3": V.rot3d(...)})`.

## Приём 1. Рамка на оси (pivot) — вращение вокруг любой точки

PowerPoint вращает фигуру вокруг центра её рамки, и Morph интерполирует угол поворота. Если рамка — квадрат с центром в точке `pivot`, а форма нарисована внутри неё со смещением, то `rot` и его морфинг вращают форму **вокруг pivot по дуге**. Обычный объект при Morph едет **по хорде**, напрямую.

```python
PIV = (4.1, 4.05)
PET = V.resample(V.petal(PIV, 0.62, 2.55, 0.98), 120)          # один контур на все лепестки
petals = [V.shape(f"!!pet{i}", PET, pivot=PIV, rot=(i - turn) * 45, fill=col[i]) for i in range(8)]
```

- **Колесо или карусель.** На следующем слайде `turn + 1`: все лепестки поворачиваются на 45° вокруг центра цветка.
- **Орбита.** Спутник — круг на радиусе R в рамке на оси солнца. Поворот рамки ведёт его по орбите.
- **Вход «Вертушка»** (`Fx("entrance_spinner")`) и выделение «Вращение» крутят такой объект тоже вокруг pivot: лепестки раскручиваются из центра цветка, как на эталонном видео.
- **Выдвинуть активный лепесток** — заменить контур на более длинный (`PET_ON`) с тем же числом точек. Morph переливает форму и вращает её одновременно.

**Правила поворота.**
- Шаг за один переход **меньше 180°**: PowerPoint крутит по кратчайшему пути (переход 315° → 0° идёт на +45°).
- Полный оборот за один Morph не анимируется: 0° и 360° — одно состояние. Его делят на 2–3 шага, промежуточные слайды переключаются сами (`Slide(auto=0)`).
- Подписи, которые должны оставаться горизонтальными, двигай обычными объектами: они едут по хорде. На шаге 45° отклонение от дуги ≈ 0,08·R — незаметно.

## Приём 2. Перелив формы (shape morph)

Morph честно переливает одну свободную форму в другую, если у обеих:
- одинаковое число точек;
- одно направление обхода;
- одна стартовая точка;
- не больше одной дырки.

`resample(g, n)` даёт всё это сразу. `lint` предупреждает, если у пары разное число точек или больше одной дырки.

```python
for k, g in enumerate([V.circle(cx, cy, 1.5), V.rect(..., r=0.45), V.star(cx, cy, 1.85, 0.78), drop]):
    Slide([V.shape("!!blob", V.resample(g, 160), fill=col[k])], …)
```

- Капля, звезда, сердце и стрелка собираются через `union`/`subtract` из примитивов, затем `resample`.
- Цвета пары держи близкими (раздел 9, п. 6а SKILL.md).
- Форма с двумя дырками и результат `combine` (кольцо с линзой) не переливаются: Morph заменит перелив затуханием.

## Приём 3. Фрагментация и разлёт (explode)

1. Слайд A: целые фигуры.
2. Слайд B: `fragment(...)` — кусочки на тех же местах, каждый со своим именем `!!fr{i}`. Переход A → B почти незаметен.
3. Слайд C: кусочки смещены от общего центра (`move(p, dx·k, dy·k)`). Morph разводит их, получается «разобранная» схема (диаграмма Венна по частям, состав целого).

Обратный ход — сборка: C → B. Каждый кусочек — своя пара, поэтому его можно перекрасить, подписать или увести на следующий слайд.

## Приём 4. 3D-поворот

`rot3d(x, y, z)` — это «Поворот объёмной фигуры» в интерфейсе PowerPoint: X — вокруг вертикали (`lon`), Y — вокруг горизонтали (`lat`), Z — в плоскости (`rev`). Morph плавно меняет 3D-поворот. Текст в фигуре поворачивается вместе с ней.

- **Переворот карточки** — два Morph подряд, промежуточный слайд переключается сам:
  - 1: лицо 0°, оборот 270° (ребром, не видна);
  - 2 (`auto=0`, 450 мс): лицо 90° (ребром), оборот 270°;
  - 3 (450 мс): лицо 90°, оборот 0°.
  
  Оборот выходит из 270° в 0° по кратчайшему пути, в ту же сторону, что ушло лицо: переворот непрерывный и без зеркального текста.
- **Изометрическая стопка:**
  - плоские плашки списком → `rot3d(x=314.7, y=324.6, z=60.2, camera="orthographicFront", depth=8)` с шагом по y — это значения пресета «Изометрия: сверху вверх»;
  - шаги конвейера «складываются» в слои архитектуры;
  - обратный переход раскладывает стопку в список.
- **Наклон карточки к зрителю** (`rot3d(x=20, camera="perspectiveFront")`) — «фокус» без увеличения.
- `depth` (pt) — выдавливание с цветом `depth_color`, `bevel` — фаска.
- Эффекты анимации 3D-моделей (`*_3d_*`) на фигурах не играют. Движение фигуры в 3D дают Morph и 3D-поворот.

**LibreOffice рисует 3D приблизительно или плоско**, поэтому 3D проверяют только в PowerPoint. На миниатюре от LibreOffice карточка с поворотом 270° видна плоской поверх лица: это особенность рендера, а не ошибка файла.

## Градиенты

- `gradient([(0, светлый), (1, цвет)], angle=90)`: `rotWithShape="1"`, градиент поворачивается вместе с фигурой.
- У формы в рамке на оси `fit=True` (по умолчанию) растягивает стопы на саму форму, а не на большую рамку. Иначе лепесток получил бы лишь кусочек градиента.
- Для ровной заливки бери близкие оттенки одного цвета: `mix(col, "FFFFFF", 0.3)` → `col`. Радужные градиенты — антишаблон.

## Проверка

- `xsd_check` — 0 ошибок. Порядок в `spPr`: xfrm → custGeom → заливка → ln → scene3d → sp3d. Движок пишет его сам.
- Импорт в LibreOffice: у каждой свободной формы есть `draw:enhanced-geometry`, у входов — `ooo-entrance-…`.
- `lint` берёт настоящий габарит формы (`bbox`): рамка на оси может выходить за слайд — это не ошибка.
- Вращение по дуге, перелив и 3D — только в показе PowerPoint.
